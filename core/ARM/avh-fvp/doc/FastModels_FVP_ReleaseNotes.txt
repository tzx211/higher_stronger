
==============================================================================
Fast Models 11.28 FVP Release Notes
==============================================================================

------------
Introduction
------------

This is a package of Fixed Virtual Platforms (FVPs) based on Fast Models
11.28.

Detailed documentation can be found at:
https://developer.arm.com/products/system-design/fast-models/docs

------------
Installation
------------

For installation instructions, see the chapter "Installing Fast Models" in the
Fast Models User Guide:
https://developer.arm.com/documentation/100965/latest/Installing-Fast-Models/Installation

A significant number of the examples make use of images containing third
party IP. These have been split out into a separate 'Third Party IP' package
that can be downloaded from:
  * Product Download Hub:
    https://developer.arm.com/downloads
Not installing these images will mean examples that require Dhrystone or the Linux
images will not be functional, and some other features might not work.

-----------------
What is supported
-----------------

Fast Models FVPs support the following operating systems:

On x86 hosts:
* RedHat Enterprise Linux 7
* RedHat Enterprise Linux 8
* Ubuntu 18.04 LTS
* Ubuntu 20.04 LTS
* Windows 10

This release provides beta support for AArch64 hosts with:
* RedHat Enterprise Linux 8
* Ubuntu 20.04 LTS

FVPs shipped with this package are built with Visual Studio 2019 and GCC 9.3.0.

-------------------------
Notices of future changes
-------------------------

* CPU cluster configurations with a static number of cores defined are
  now deprecated. Customers will need to migrate their systems to equivalent
  CPU clusters that support a configurable number of cores using the
  "NUM_CORES" parameter.

  Example platforms and CPU clusters with a statically-defined number of
  cores will be retired in future releases.

--------------------------------------------------------
Changes in Fast Models 11.28
--------------------------------------------------------

* The defaults of some AEM parameters on FVP_Base platforms have been changed
  to enable faster simulation performance by default:
  * The default value of cache_state_modelled has been changed from true to
    false.
  * The default value of cluster-level parameter check_memory_attributes has
    been changed from true to false.
  * The default value of cluster-level parameter stage12_tlb_size has been
    changed from 128 to 1024.
  These changes align the defaults with those used for non-AEM models. The old
  values can still be set manually and function the same as before.

* From early 2023, new licenses generated for Fast Models will provide
  an alternative and simplified set of license features for enabling the
  IP models. This will mean that no further license updates are needed
  as new models become available in future releases. Licenses containing
  the existing set of features will continue to work, however users are
  encouraged to regenerate and deploy updated licenses after this point
  to benefit from this change and to enable access to future models.

* The following models are not yet at full release quality. However, they
  have been added to the Fast Models Portfolio to make them available. Please
  see the documentation for the individual components, which describes their
  quality:
  - Cortex-R82
  - Cortex-A34
  - NI-700

* Support has been added for the following models:
  - Cortex-X4
  - Cortex-A720
  - Cortex-A520
  - Mali-G720

* The Cortex-R52+ model is now fully supported.
